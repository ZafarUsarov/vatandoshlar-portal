# Roadmap

This roadmap describes the planned evolution of Vatandoshlar.de.

The project is developed incrementally. Each milestone has a clear scope and should be completed before the next milestone begins.

New feature ideas should be added to the backlog and must not interrupt the active milestone unless their priority changes.

---

# Project Vision

Vatandoshlar.de aims to become the leading information platform for Uzbek people living in Germany or planning to move to Germany.

The platform will provide trustworthy information, practical guidance, job opportunities, public services, educational resources, events, and community support.

The long-term objective is to build a scalable, multilingual, production-quality platform rather than a simple informational website.

---

# Development Principles

Every milestone should:

- have a clear goal;
- be independently testable;
- avoid unnecessary dependencies;
- preserve existing functionality;
- improve maintainability;
- leave the repository in a stable state.

Every meaningful change should have:

- its own Git commit;
- documentation when necessary;
- code review before merge.
