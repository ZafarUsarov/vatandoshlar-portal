# 🇩🇪 Vatandoshlar.de

A modern community platform for Uzbeks living in Germany.

The project brings together essential information, services, job opportunities, events, Telegram communities, and practical guidance for people who live in Germany or plan to move there.

This repository contains the frontend application built with Next.js App Router and follows a scalable architecture designed for future multilingual support, an admin portal, and database integration.

---

# Vision

Our goal is to build the largest digital platform for the Uzbek community in Germany by providing reliable, well-structured, and easy-to-access information.

The platform is designed to become more than a website. It aims to serve as a long-term ecosystem including:

- News
- Services
- Jobs
- Events
- Telegram Communities
- Germany Guide
- Administrative Portal
- Content Management System
- AI-assisted content management
